    MCP Tools for

    Memory & Notify

    Memory is off by default. Memory belongs to this device and is shared by everyone who uses it. It does not identify individual speakers. Only enable it when everyone using this device agrees.

    Device connection

    WebSocket is the default and keeps the existing voice setup. MQTT enables persistent control for notifications. Saving a transport closes the current voice connection and changes the next OTA configuration; reboot the device or make it fetch OTA again to use it. This panel does not reboot or flash your device.

    Device memory

    Enabling memory stores completed Gemini conversation turns and uses saved facts and recent turns on the next Gemini connection. Transcripts are enabled for storage independently of the device’s display preferences. Turning memory off and saving clears stored facts and turns and closes the current voice connection to remove loaded context. The device must reconnect.

    One fact per line, up to 20 facts and 500 characters per fact. These are explicitly saved facts, not automatically inferred claims. Changes take effect only after Save memory.

    Recent turns (read-only)

    Most recent 20 stored turns. Voice-only or interrupted responses may have no complete text to save.

      Forget memory

      Permanently delete this device’s stored facts and recent turns and close its current voice connection to remove loaded context. This cannot be undone. The device must reconnect. The enabled setting stays unchanged; an enabled device can save new turns on its next Gemini connection. Type the device address exactly to confirm.

      Notification inbox

      Unread messages request a reminder beep while the device is idle. Greet the device to hear titles first; completed title responses mark those messages read. Ask for details to hear the full message. Opening a message here does not mark it read. Publication does not confirm playback.

        Message

          Test message & beep

          Use your existing admin login to test the complete flow. No Hermes or external sender token is needed. The message is saved first; the beep may be unavailable when notifications are disabled or the device is offline, busy, or using WebSocket. Retry the beep from the saved message without creating another message.

          Sender permissions, secrets, retention, and numeric memory/inbox limits are configured server-side. This dashboard does not display or edit secrets.

          Audio-only test (no inbox message)

          This separate test plays prerecorded audio and optional subtitles. It does not save an inbox message.

          Use a local recording below, or a direct HTTPS URL on an operator-approved audio origin (NOTIFY_ALLOWED_AUDIO_ORIGINS). External audio must return a 2xx response with mono Ogg Opus audio. The device downloads it; the dashboard and relay never fetch an external URL.

          Notifications are disabled until the MQTT gateway is enabled and configured and this device is explicitly set to MQTT. After saving MQTT, reboot/fetch OTA and connect the device. It must be online and idle; stock firmware can ignore a request while busy. There is no offline queue. A published result confirms publication only; playback and whether anyone heard it remain unknown.

          The bundled sample-chime.ogg is a one-second test tone with no speech. Using a recording creates a five-minute download link; it does not send a notification or synthesize speech.

          Closing this window stops waiting for a response. A request already submitted may still complete; reopen to refresh stored memory and the inbox. Pending message and beep retry IDs are kept while this page stays open; check the inbox before sending after a page reload.

                  Pomodoro · Edge TTS

                  Pengumuman suara langsung satu kali, tanpa pesan inbox. Memerlukan MQTT, URL audio yang dapat diakses perangkat, serta internet untuk Edge TTS pertama kali. Jika offline, jam tenang, atau terlambat lebih dari 2 menit, pengumuman dilewati. Fokus dan istirahat berganti otomatis; sapaan tidak mengubah timer.

                  Hari aktif (hari mulai jika melewati tengah malam)

                  Fokus 25 menit → istirahat 5 menit. Setelah 4 sesi fokus selesai, istirahat panjang 20 menit. Jeda membekukan sisa waktu; lanjutkan meneruskan fase yang dijeda atau kembali fokus jika sedang istirahat. Lewati fase tidak menghitung fokus yang dilewati sebagai selesai.
