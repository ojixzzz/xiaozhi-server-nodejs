# Operator-supplied MQTT TLS certificates

This directory is mounted read-only at `/run/mqtt-tls` in the gateway container.
For TLS, supply a certificate chain trusted by the firmware for your MQTT hostname
and its matching private key, then set MQTT_TLS_CERT_FILE and MQTT_TLS_KEY_FILE.
No certificate/private key is supplied or generated by this project.
The unprivileged container user (UID 1000) needs read access; do not make private
keys world-readable. Contents other than this README are ignored by Git and
excluded from Docker image builds. Never upload private keys in chat.
